# Success Metrics

## Purpose

Defines how product success will be measured after launch. Metrics cover adoption, activation, engagement, reliability, customer value, and guardrails to ensure that increased usage does not negatively affect product quality.

## North Star Metric

Successful automated operational outcomes.

## Adoption

- % of eligible customers creating workflows
- Number of active workflows
- Number of customers with active workflows

## Engagement

- Workflow executions per customer
- Weekly active workflow users
- Number of workflows created per customer

## Quality

- Successful execution rate
- Workflow failure rate
- Error recovery rate

## Customer Value

- Manual operations avoided
- Average time saved per automated process
- Time to first successful workflow

## Guardrail Metrics

- Incorrect automation rate
- Workflow disablement rate
- Support cases related to workflow execution
