# User Stories

## Epic: Workflow Creation

### US-01 — Create Workflow

As an IT administrator,

I want to create a workflow,

so that I can automate a recurring operational process.

### US-02 — Select Trigger

As an IT administrator,

I want to select an event that starts the workflow,

so that automation happens when the relevant event occurs.

### US-03 — Add Condition

As an IT administrator,

I want to define conditions,

so that the workflow only executes for relevant events.

### US-04 — Configure Action

As an IT administrator,

I want to select an action,

so that the system can perform the required operational task.

### US-05 — Preview Workflow

As an IT administrator,

I want to review my workflow before enabling it,

so that I can verify the intended behavior.

### US-06 — Monitor Execution

As an IT administrator,

I want to see workflow execution history,

so that I can understand whether automation is working correctly.
